# Arabic Sentiment Workspace

Public front end for the private Arabic sentiment analysis project. The dataset, uploads, workbooks, and processing records stay in the private repository. Do not add project data to this repository.

Open the workspace website, connect with a fine-grained token for the private project repository, then upload raw files or publish classified files. The token is held in the active browser tab and sent only to GitHub.

This repository contains only the static interface and empty workbook templates.
